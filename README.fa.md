# اتودار، مدیریت نمایشگاه خودرو

یک پنل راست‌چین و ریسپانسیو برای مدیریت نمایشگاه خودرو با **Next.js 14، MongoDB و Mongoose**. این نسخه عمداً بدون کران‌جاب ساخته شده: مقایسه بازار از فایل `data/market-prices.json` خوانده می‌شود و بعداً می‌توان منبع به‌روزرسانی را به همین لایه وصل کرد.

## امکانات پیاده‌سازی‌شده

- داشبورد مدیر: موجودی، ارزش روز، سود واقعی، خواب سرمایه، چک‌های نزدیک، مطالبات و پیگیری امروز
- پرونده کامل خودرو: مدل، سال، رنگ، کارکرد، VIN، موتور، پلاک ایرانی، عکس، مالکیت ملکی/امانی و وضعیت فروش
- قیمت تمام‌شده با هزینه‌های کارشناسی، حمل، تعمیر، واسطه، اداری و آماده‌سازی
- سود اسمی، هزینه فرصت خواب سرمایه و سود واقعی هر پرونده
- شرکا، درصد سرمایه و تقسیم سود به تفکیک نفر
- کمیسیون ثابت یا درصدی و وضعیت پرداخت
- دفتر چک با سررسید، هشدار ۷ روزه و ثبت وصول/برگشتی
- دفتر نقدینگی و تسویه معامله
- مقایسه با آگهی و معامله واقعی، میانه بازار و بازه پیشنهادی فروش
- مشتری، منبع لید، بودجه، خودروی موردعلاقه و فالوآپ
- موجودی نمایشگاه‌های همکار
- چک‌لیست مدارک خودرو، بیمه، معاینه فنی، انتقال سند و خروجی CSV قابل تطبیق با نرم‌افزار حسابداری/سامانه مودیان
- ربات تلگرام: `/report`، `/cheques`، `/dormant` و مسیر آماده برای ارسال گزارش از کران‌جاب آینده
- تاریخ شمسی و نمایش قیمت به رقم و حروف فارسی

## اجرا

```bash
cp .env.example .env.local
# MONGODB_URI را روی MongoDB خودت بگذار
npm install
npm run dev
```

سپس به `/api/seed` یک درخواست `POST` بفرست تا داده نمایشی ساخته شود:

```bash
curl -X POST http://localhost:3000/api/seed
```

برای بازنشانی کامل داده نمایشی در محیط توسعه:

```bash
curl -X POST 'http://localhost:3000/api/seed?reset=1'
```

## تلگرام

1. در BotFather ربات بساز و `TELEGRAM_BOT_TOKEN` را در `.env.local` بگذار.
2. به ربات `/start` بفرست.
3. شناسه چت را در تنظیمات پنل وارد کن.
4. برای وبهوک روی دامنهٔ HTTPS:

```bash
curl "https://api.telegram.org/botTOKEN/setWebhook?url=https://DOMAIN/api/telegram/webhook"
```

در ایران ممکن است لازم باشد `TELEGRAM_API_BASE` را روی رله یا پراکسی Bot API خودت بگذاری.

برای کران‌جاب آینده، مسیر آماده است:

```text
GET /api/notify?secret=NOTIFY_SECRET&type=digest
GET /api/notify?secret=NOTIFY_SECRET&type=cheques
GET /api/notify?secret=NOTIFY_SECRET&type=dormant
```

## داده بازار

فرمت فایل `data/market-prices.json`:

- `type: ad` برای آگهی دیوار/باما
- `type: deal` برای معامله واقعی
- فیلدهای اصلی: `brand`, `model`, `year`, `mileage`, `price`, `source`, `date`

داده موجود در این فایل **کاملاً آزمایشی و غیرواقعی** است و فقط برای تست رابط و محاسبات استفاده می‌شود.

## نکته مالیاتی

خروجی `/api/export/invoices` یک CSV آماده برای نگاشت به نرم‌افزار حسابداری است، نه تضمین اتصال مستقیم به سامانه مودیان. قالب نهایی صورتحساب را قبل از استفاده عملی با شرکت معتمد یا حسابدار مجموعه تطبیق بده.
