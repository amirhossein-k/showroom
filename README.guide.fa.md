# افزودن راهنمای درون‌برنامه‌ای

## نصب (۳ قدم)
1. این فایل‌ها را با همان مسیرها در ریپو کپی کن:
   - `lib/guide.js` (همه متن‌های راهنما؛ برای تغییر متن فقط همین فایل را ویرایش کن)
   - `components/PageGuide.jsx` (کارت «راهنمای این بخش» بالای هر صفحه)
   - `app/guide/page.js` (صفحه کامل راهنما در `/guide`)
   - `scripts/add-guide.mjs` و `GUIDE.fa.md`
2. از ریشه پروژه: `node scripts/add-guide.mjs`
   این اسکریپت `components/Shell.jsx` را پچ می‌کند: آیتم «راهنما» به منو اضافه می‌شود و `<PageGuide />` بالای محتوای همه صفحه‌ها قرار می‌گیرد (نسخه قبلی: `Shell.jsx.bak`).
3. `npm run dev`، تست کن، commit و push کن تا Vercel دوباره deploy کند.

## رفتار
- بار اول که کاربر وارد هر بخش می‌شود، راهنمای همان بخش باز است. با «فهمیدم» جمع می‌شود و فقط دکمه کوچک «❔ راهنمای این بخش» می‌ماند.
- در صفحه `/guide` دکمه «نمایش دوباره راهنمای همه صفحه‌ها» همه را دوباره باز می‌کند.
- در صفحه چاپ قولنامه و صفحه ورود راهنما نمایش داده نمی‌شود.
- اضافه کردن بخش جدید: یک آیتم به `GUIDE_SECTIONS` در `lib/guide.js` اضافه کن (الگوهای دقیق‌تر بالاتر).
